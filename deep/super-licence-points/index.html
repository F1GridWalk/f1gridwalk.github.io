F1のレースに出るための「40点」は、どうやって集めるのか

キャデラックのテストドライバー、コルトン・ハータが、F1に乗るためのスーパーライセンスの点数を集める道として、日本のスーパーフォーミュラも選択肢になり得ると、英PlanetF1が分析した。F1のレースに出るには、なぜ40点が要るのか。どのレースで何点もらえるのか。スーパーライセンスの仕組みを、ハータの例からほどく。

2026年10月16日(金) 19:05 公開本文 約5分

規則ドライバー
先に結論ハータに足りない点なぜ「40点」なのかどのレースで、何点もらえるのかフリー走行は「1戦1点」点数の壁と、スーパーフォーミュラの2位データと記録出典
先に結論
  1. F1のレースに出るには、FIAのスーパーライセンスが要る。いちばん大事な条件は「点数」で、申請の前の3年、または前の2年と申請の年の成績で、40点以上を集めなければならない（FIA国際モータースポーツ競技規則 付則L）。
  2. 点数は、選手権と順位で決まる。F2の王者と2位・3位は40点、インディカーの王者は40点、スーパーフォーミュラの王者は30点。下のカテゴリーほど点は少ない。
  3. F1のフリー走行で100km以上を、ペナルティポイントなしで走ると、1つのグランプリにつき1点。ただし、数えられるのは最大10点まで（F1公式サイト）。
  4. ハータは2022年、点数が足りずにスーパーライセンスを認められなかった。今季はF2に移ったが表彰台がなく、英PlanetF1は、インディカーで3位以内か、スーパーフォーミュラで2位以内に入り、さらにキャデラックでフリー走行を重ねることが、F1への道になるとしている。
  5. 点数以外にも、18歳以上、規則の試験、2シーズンの単座の選手権を80%以上走っていることなどの条件がある。かつてあった運転免許の条件は、2024年になくなった。
理由と背景

ハータに足りない点

コルトン・ハータは、インディカーで勝利を重ねたアメリカ人ドライバーだ。今季はキャデラックのテストドライバーを務めながら、F1への足がかりとしてF2（ハイテック）に移った。ところが、英PlanetF1によると、F2では表彰台に届かず、9月の時点でランキング19位。同サイトは、このまま19位で終われば、スーパーライセンスの点にはならない、と書いている。

PlanetF1は7月の時点で、ハータの点数を35点、あと5点足りないとしていた。その後ハータ本人は、ドイツのF1-Insiderに「あと2点足りない」と話している（PlanetF1が伝えた）。

PlanetF1は10月15日、ハータの今後の道として、インディカーに戻ってランキング3位以内に入るか、スーパーフォーミュラで2位以内に入るかのどちらかに、キャデラックでのフリー走行への出走を重ねること、を挙げた。日本のF1-Gate.comはこれを伝えたうえで、ハータが日本のチームと交渉しているという情報はない、と書いている。

なぜ「40点」なのか

F1のスーパーライセンスの条件は、FIAの国際モータースポーツ競技規則の付則Lに書かれている。2026年版によると、主な条件は次のとおりだ。

条件中身
ライセンスFIAの国際Aライセンスを持っていること
年齢最初のF1の競技の時点で18歳以上（単座での際立った能力と成熟を示せば、FIAの判断で17歳も可）
規則の知識初回の申請時に、国際競技規則とF1の競技規則についての試験
経験付則Lの付表1に載った単座の選手権を、2シーズンそれぞれ80%以上走っていること（初回の申請時）
点数40点以上。申請の前の3年か、前の2年と申請の年の、多いほうで数える

出典：FIA国際モータースポーツ競技規則 付則L（2026年版）13.1。

点数の決まりには例外もある。30点以上あって、本人にはどうにもならない事情で40点に届かなかったときは、FIAの判断で認められることがある。その場合は、申請前180日以内に、F1の車で2日以内に300km以上をレースの速さで走る必要がある。

どのレースで、何点もらえるのか

点数は、選手権とランキングの順位で決まる。いちばん高いのはF2で、1位から3位までが40点。インディカーの王者も40点だ。インディカーは2026年から配点が見直され、3位から9位までの点が引き上げられた（The Race）。

スーパーフォーミュラは、2025年から王者に30点、2位に25点、3位に20点が与えられるようになった。FIAは見直しの理由に、F1以外で最も速い単座のシリーズの一つであることを挙げている（GPFans）。それ以前の王者は25点だった（英語版Wikipedia）。

フリー走行は「1戦1点」

選手権の成績のほかに、F1のフリー走行でも点がもらえる。F1公式サイトの解説によると、フリー走行専用のスーパーライセンスを持つドライバーは、1つのグランプリのフリー走行で100km以上を走り、ペナルティポイントを受けなければ1点。ただし、数えられるのは最大10点までだ。

PlanetF1は、ハータのキャデラックでのフリー走行1回目が4回の予定で、それだけでは足りないおそれがある、と書いている。PlanetF1によると、ハータは今季、モナコでのF2のレースで、VSC中の追い越しによりペナルティポイント2点を受けた。これで、ペナルティポイントなしでシーズンを終えればもらえた2点のボーナスを逃した。

点数の壁と、スーパーフォーミュラの2位

ハータが点数の壁にぶつかるのは、これが初めてではない。2022年、アルファタウリへの移籍の話が出たとき、FIAは、所定の経路で問い合わせがあったことを認めたうえで、ハータは「スーパーライセンスを与えるのに必要な点数を持っていない」とした。米Sports Illustratedによると、当時は40点のところ32点だった。

スーパーフォーミュラの2位から、F1への道を開いた人もいる。2017年のピエール・ガスリーは、最終戦の鈴鹿が台風で中止になり、王者の石浦宏明にわずか0.5点届かず、ランキング2位に終わった。2023年のリアム・ローソンもスーパーフォーミュラで2位だった。

F1 Grid Walk編集部としては、スーパーライセンスの40点は、F1の席が「速さ」だけでなく「どこで、どれだけ結果を残したか」で決まる仕組みだと見ています。インディカーやスーパーフォーミュラの配点が見直されてきたのも、どのシリーズの結果をどう数えるかが、そのまま才能の通り道を決めるからです。ハータが残りの点をどこで集めるのかは、まだ決まっていません。
