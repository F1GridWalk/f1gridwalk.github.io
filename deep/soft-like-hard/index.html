F1シンガポールのソフトは、なぜ「ハードみたい」に長持ちしたのか

シンガポールGPで、いちばん柔らかいソフトが44周を走り、いちばん硬いハードは決勝で誰も使わなかった。ウィリアムズのアルボンは「ソフトというより、ハードのように感じた」と話し、カギは今季高くなったタイヤの空気圧にあると見る。なぜ空気を増やしたのか、空気が多いとタイヤに何が起きるのか。分かっていることと、まだ分からないことを分けてほどく。

2026年10月15日(木) 13:53 公開本文 約9分

タイヤマシンと空力作戦
先に結論シンガポールで起きたことなぜ空気を増やしたのか空気が多いと、タイヤに何が起きるか同じ年に、正反対のこともなぜ下げないのかデータと記録出典
先に結論
  1. シンガポールGPの主役は、いちばん柔らかいC5のソフトだった。ハミルトンは1セットで44周を走り、決勝でハードを使った車は1台もなかった（ピレリ）。同じC3〜C5の組み合わせだった2025年は、ハードが2回目のスティントでいちばん多く選ばれていた。
  2. ウィリアムズのアルボンは「ソフトというより、ハードのように感じた」と話し、理由は「リアの空気圧が大きく跳ね上がっている」ことだと見る。いまは柔らかいタイヤのほうがグリップがあるように感じ、表面の温度を管理しやすいという。
  3. 空気圧が高いのは、今季から入ったアクティブエアロの安全策だ。翼がコーナー用の形のまま直線を走ると、タイヤに大きな力がかかる。そのときに壊れないよう、ピレリが決める最低の空気圧は、コースによって2025年より3〜4psiほど高いことが多い（The Race）。シンガポールでは、前が22.0psiから24.0psi、後ろが20.0psiから23.0psiになった（FIAの資料）。
  4. 空気が多いと、地面に触れる面が小さくなり、グリップは減る。シンガポールとは逆に、暑く路面の粗いバルセロナでは、ハースのベアマンが「タイヤに空気がすごく多く入っていて、本当に悪夢だ」と話すほど、オーバーヒートに苦しんだ。ピレリは原因を、路面の粗さや温度の高さに挙げている。
  5. 空気圧を下げる案（コーナーモードのまま5周走った車を、黒とオレンジの旗でピットに呼ぶ案）は、チームの賛成が足りず通らなかった。The Raceによると、高い空気圧は今季の残りと、おそらく2027年も続く。
理由と背景

シンガポールで起きたこと

10月11日のシンガポールGPで、ピレリが持ち込んだのは、C3（ハード）、C4（ミディアム）、C5（ソフト）の3種類。2025年と同じ組み合わせだ（F1公式サイト）。決勝で使われたのは、ソフトとミディアムだけだった。

ピレリのレース後のまとめによると、ソフトの1セットでいちばん長く走ったのはハミルトンの44周。ミディアムではラッセルが39周を走った。ピレリのダリオ・マラフスキは、こう話している。

「C5がレースの主役だった。とても長いスティントを、高い性能を保ったまま走った」

— マラフスキ（ピレリ）

ハードは誰も選ばなかった。マラフスキによると、ハードはC4のミディアムよりグリップが低かった。C4は劣化が「ほとんどなかった」ので、1ストップを前提にしたレースでは、ハードを使う利点がなかったという。

1年前はどうだったか。2025年のシンガポールGPのピレリのまとめでは、2回目のスティントでいちばん多く選ばれたのはハード。イゾラによると、ミディアムで50周、ソフトで38周のスティントがあった。当時ピレリのモータースポーツ・ディレクターだったマリオ・イゾラは、グリッドに向かう直前に降った雨もあって、ソフトが「興味深い選択肢になった」と話していた。

同じコースで、同じC3〜C5という組み合わせなのに、使われ方は大きく変わった。ただし2025年はスタート前の雨で路面が少し湿っていたうえ、2026年はタイヤそのものも新しくなっている。新しい規則で、タイヤは細く、外径も小さくなった。F1公式サイトによると、前は25mm、後ろは30mm小さくなった。空気圧だけがソフトを長持ちさせた、とまでは言い切れない。

それでも、走ったドライバーの実感ははっきりしていた。ウィリアムズのアレクサンダー・アルボンは、RacingNews365にこう話している。

「今回のレースのソフトはとても良かった。むしろ良すぎたくらいだ」

— アルボン（ウィリアムズ）

「ソフトがあれだけの周回を、あれだけ安定して走れるのは普通じゃないと思う」

— アルボン（ウィリアムズ）

「すばらしいタイヤで、ソフトというよりハードのように感じた」

— アルボン（ウィリアムズ）

なぜ空気を増やしたのか

理由は、今季から入ったアクティブエアロにある。直線では翼を寝かせた「ストレートモード」、コーナーでは立てた「コーナーモード」に切り替わる。英The Raceによると、もし故障でコーナーモードのまま直線を走ると、ダウンフォースが大きいまま最高速に達し、タイヤに大きな力がかかる。そのときでも壊れないように、ピレリは最低の空気圧を高めに決めている。

ピレリのチーフエンジニア、シモーネ・ベラはシーズン前から、これとは別の場面、つまりブレーキングでストレートモードが切れてコーナーモードになる瞬間について、「荷重が大きく増えるので、私たちにとって最も厳しい条件になる」と話していた（The Race）。翼の切り替えは、タイヤにとって新しい負担になっている。

The Raceによると、この安全策のため、空気圧はコースによって2025年より「3〜4psiほど高い」ことが多い。FIAが公開するピレリの事前資料では、鈴鹿の最低スタート空気圧は、2025年が前24.5psi・後ろ23.5psi、2026年は前28.0psi・後ろ25.0psiだった。シンガポールは、2025年が前22.0psi・後ろ20.0psi、2026年は前24.0psi・後ろ23.0psi。前より後ろのほうが大きく上がっている。

ただ、どのコースでも同じように上がったわけではない。上海では2025年、再舗装した路面でフロントにひどいグレイニングが出て、最低空気圧が2回引き上げられ、最後は前27.5psi・後ろ24.0psiになった（RaceFans）。2026年の事前の値（前26.5psi・後ろ24.5psi）と比べると、前はむしろ低い。

ドライバーの不満は早くから出ていた。メルセデスのジョージ・ラッセルは、7月2日のRacingNews365の記事で、こう話している。

「どこかのチームのストレートモードが壊れたら、ダウンフォースがずっと大きくなる。そのために2〜3psiの上乗せが必要になる。でも僕らみんなにとっては、大きな風船の上を走っているようなものだ」

— ラッセル（メルセデス）

空気が多いと、タイヤに何が起きるか

タイヤの内圧を下げると、地面に触れる面（接地面）が大きくなり、使えるグリップが増える。英The Raceの技術記者マーク・ヒューズは、最低空気圧が決められているのは「タイヤのグリップと、構造にかかる負担を抑えるため」だと説明している。逆に言えば、空気を増やすと接地面は小さくなり、グリップは減る。

The Raceは2025年のバーレーンGPの記事で、空気圧の高いタイヤは滑りやすく、滑るとさらに熱を持ち、その熱で空気圧がまた上がって扱いにくくなる「悪循環」に陥りうると書いている。

ではなぜ、シンガポールのソフトは長持ちしたのか。アルボンの見方はこうだ。

「いま起きているのは、リアの空気圧が大きく跳ね上がっているということだと思う。いまは柔らかいタイヤのほうがグリップがあるように感じる。だから、表面の温度を少しうまく管理できる」

— アルボン（ウィリアムズ）

アルボンの説明は、空気圧が上がったいまは、グリップの高いソフトのほうが表面の温度を管理しやすい、というものだ。マレーシアGPの金曜には、ピレリのベラも「ソフトは、ときにミディアムより安定していた。グリップが高いので滑りが少なく、そのぶん熱が出にくいからだ」と話していた（ピレリ、DEEP GRID #08「F1セパン決勝のタイヤ【後編】ソフトが31周。あなたなら、この理由をどう説明する？」）。ただしこれは暑いセパンについての発言で、空気圧には触れていない。空気圧とソフトの長持ちの関係を、ピレリが数字で説明したものは、まだ見つかっていない。

同じ年に、正反対のことも

今季、タイヤがいつも長持ちしているわけではない。6月のバルセロナGPでは、逆のことが起きた。The Raceによると、金曜の路面温度は52℃。ハースのオリバー・ベアマンはこう話している。

「いまはタイヤに空気がすごく多く入っていて、本当に悪夢だ。劣化がすごく大きくて、1周のうちにかなりオーバーヒートする」

— ベアマン（ハース）

ハミルトンも「ここでは、僕が走ったどの年よりも、たぶんいちばんグリップが低い」と話した。ベラは金曜の走行で「前も後ろも、熱による大きな劣化があった」とし、2周かけて冷やしても、タイヤの骨格（カーカス）の温度が高いまま下がらないと説明している。

バルセロナでベラが挙げた劣化の原因は、路面の粗さ、コースが求めるエネルギー、路面温度の高さで、空気圧には触れていない。一方でピレリは金曜のあと、前後とも最低空気圧を1psi下げた。2025年のバルセロナは前26.0psi・後ろ22.0psi、2026年は後ろを25.0psiに上げていたが、下げたあとは前25.0psi・後ろ24.0psiになった（The Race、FIAの資料）。

シンガポールでは逆に、ソフトが長く走った。この違いを空気圧でどこまで説明できるかは、分かっていない。

なぜ下げないのか

空気圧を下げる案はあった。The Raceによると、ピレリは、コーナーモードのまま5周走った車に黒とオレンジの旗を出し、ピットに入れて、直せなければレースを続けさせない、というルールを提案した。そうすれば安全策の分の空気圧がいらなくなる。ベラによると、下げられる幅はコースによって前後で「1〜3psiほど」で、後ろはもっと下げられるという。

FIAはこの案を実行できると見ていたが、通すにはチームの特別多数の賛成が必要だった。多くのチームが賛成しなかった。必要ないと考えたチームのほか、シーズンの途中で速さの関係が変わるのを嫌ったチーム、翼の故障だけで良い結果を失うのを心配したチームもあったという。ベラはこう話している。

「多数が高い空気圧を続けると決めた。私たちにはそれで問題ない」

— ベラ（ピレリ）

「（空気圧を決めるときは）最悪のケースを前提にする」

— ベラ（ピレリ）

アルボンは、もっと踏み込んだ。

「（空気圧を上げたのは）ストレートモードの規則のせいだ。でも僕は、そんな規則はなくしてほしい。ストレートモードが壊れたら、どうせそこでレースをやめるしかないんだから」

— アルボン（ウィリアムズ）

The Raceによると、高い空気圧は今季の残りと、おそらく2027年も続く。一方でF1-Gate.comによると、ピレリは2027年、劣化が大きいタイヤを用意する考えだ。同サイトは、今季は1ストップで走り切るレースが多いことを背景に挙げている（「ピレリ、2027年タイヤは劣化を意図的に増加。1ストップ偏重の是正へ」）。

F1 Grid Walk編集部としては、今季ソフトが主役になるレースが続いているのは、高い空気圧が全体のグリップを下げ、そのなかでグリップの高いソフトが有利になっている面があると見ています。ただ、暑くて路面の粗いバルセロナのように逆に出たレースもあり、車もタイヤも大きく変わった年です。空気圧だけで説明できるかどうかは、まだ分かりません。次のオースティンで、どのタイヤが何周走るかは、その答え合わせの一つになりそうです。
