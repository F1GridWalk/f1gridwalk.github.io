今季まだ、雨のレースがない

今季のF1は、新しい車になってから、まだ一度も本格的な雨の決勝を走っていない。その初めての雨が、セパンで来るかもしれない。雨のタイヤは何が違い、いつ替えるのか。雨になると、決まりの何が変わるのか。決勝の前に、雨のレースの見方をほどいていく。

先に結論
  1. 雨のタイヤは2種類。緑のインターミディエイト（浅い溝）と、青のフルウェット（深い溝）だ。溝で路面の水をかき出し、タイヤが水に浮くのを防ぐ。
  2. 替えどきの目安は、ラップタイム。ピレリによると、乾いた路面のタイムを100%とすると、110〜112%まで遅くなったらインターミディエイトに替える時期だ。
  3. 雨の決勝では、「2種類のドライタイヤを使う」決まりがなくなる。DEEP GRID #04で見た「2回止まるか、3回止まるか」の計算は、雨が降れば一から変わる。
  4. 今季の車は、雨でほとんど走っていない。英Motorsport.comによると、新しい規則の車での雨の決勝は、まだ一度もない。FIAは今季、雨の時はブーストを使えないようにした。
  5. ピレリのチーフエンジニアは、セパンを「雨が降るのに完璧なサーキット」と話す。ただ「ここで降ると、ものすごい量になる」。決勝のスタート時の雨の確率は、およそ50%という予報だ。
理由と背景

今季、まだ雨の決勝がない

英Motorsport.comによると、F1は、新しい技術規則の車での初めての雨の決勝を、まだ待っている状態だ。英PlanetF1は7月の時点で、今の車で雨の中を走ったドライバーは雨の中を走った数少ないドライバーとして、ハミルトン（4月のフェラーリのテスト）とガスリー（1月のアルピーヌのシェイクダウンと、5月のピレリのテスト）を挙げていた。

走ったドライバーの感想は厳しい。英formula1news.co.ukによると、ガスリーは1月のシルバーストンを「ひどかった」と振り返り、ハジャーは今の車の雨の走りを「危ない」と表現した。ピレリのチーフエンジニアのシモーネ・ベラは「エンジニアとしては、もっとフィードバックとデータがほしい」と話している。

PlanetF1によると、ピアストリはこう話した。

「今のパワーユニットは、走りが一定でないのを嫌う。雨の中で一定に走るのは、ほぼ不可能だ。だから、いくつか問題が出ると思う。」

— ピアストリ

2種類の雨のタイヤ

雨のタイヤは2種類ある。英PlanetF1の解説によると、緑のインターミディエイトは、浅い溝で少しの水たまりをかき出す。青のフルウェットは、深い溝で、いちばん激しい雨に対応する。

溝がかき出す水の量は大きい。ピレリによると、時速300kmで、インターミディエイト1本は毎秒35〜40リットルの水を飛ばす（2020年の説明）。F1公式サイトの解説では、フルウェットは毎秒85リットルとされた（2022年）。今季のタイヤは、それより幅も直径も小さくなっている。

ただし、フルウェットには弱点がある。F1公式サイトの解説者のパーマーは、フルウェットが飛ばした水は後ろの車の前で「しぶきの幕」になり、ドライバーにとっては、水に浮くことより前が見えないことの方が大きな問題になると書いている。インターミディエイトが使える路面なら、フルウェットより「段違いに速い」ので、チームはできるだけ早くインターミディエイトに替えたがる。

英PlanetF1によると、今季はタイヤを温める「タイヤウォーマー」の温度も変わった。インターミディエイトは最高70℃まで温められ、フルウェットも最高40℃まで温めてよいことになった。安全上の理由からだ。フルウェットは当初、ウォーマーなしの予定だった。

いつ替えるのか

替えどきを決めるのは、ラップタイムだ。ピレリの説明では、乾いた路面のタイムを100%とすると、110〜112%まで遅くなったら、インターミディエイトに替える時期。乾いた時に1分30秒の周回なら、1分40秒ほどになったあたりだ。

セパンに当てはめると、どうなるか。英The Raceが伝えた金曜のフリー走行2回目のロングランの平均（1分44秒台後半）を100%とすると、110〜112%は1周およそ1分55秒〜1分57秒台になる。決勝でラップタイムがこのあたりまで落ちてきたら、インターミディエイトに替える時期の目安だ。ただし、金曜の平均はタイヤの種類も周回数も人によって違い、燃料の量も分からないので、あくまで目安の計算になる。

逆に、路面が乾いてきたのにインターミディエイトのまま走ると、1周で5〜6秒失うこともあるとピレリは説明している。雨の降り始めと、路面が乾き始める時。1周早いか遅いかで、順位が大きく動く。

早すぎても失敗する。2009年のマレーシアGPでは、ライコネンが雨の予報を見てフルウェットに早めに替えたが、本降りになる前で路面に水が足りず、タイヤが傷んでペースを落とすことになった。

F1 Grid Walkとしては、今日のセパンでいちばん見たいのは「最初にタイヤを替える1台」だと見ています。どのチームも今の車の雨のデータがほとんどないので、誰が先に動き、それが当たるかどうかで、レースの流れが決まりそうです。

雨になると、決まりの何が変わるか

乾いた決勝では、少なくとも2種類のドライタイヤを使わなければならない。英PlanetF1によると、雨のタイヤを使うレースでは、この決まりは当てはまらない。前のDEEP GRID #04で書いた「2回止まるか、3回止まるか」の計算は、雨が降れば一から組み直しになる。

今季は、雨の時のための決まりも足された。英The Raceによると、FIAは、路面が滑りやすい時にはブーストモード（最大350kWの電気の力を一気に足す機能）を使えないようにした。電気の出し方にも上限を設け、直線で開く可動ウイングも、雨の時は一部しか開けないようにした。5月のマイアミGPの週末から適用されている。

セパンの雨は、量が違う

英Motorsport.comによると、ピレリのベラは、セパンを「雨が降るのに完璧なサーキット」と話した。ガスリーも、路面が粗く、暑く、高低差もあるので水が抜けやすいと見ている。アントネッリは「普通の雨なら、舗装の目がとても粗いので、水が表面に溜まらない」と話している（オランダGPblog）。

ただし、ベラはこうも話した。「ここで降ると、ものすごい量になる」。だから、決勝ではフルウェットが主役のタイヤになると見ている。ふだんチームはインターミディエイトを好むので、珍しいことだという。逆に、雨のあと急に乾くと、雨のタイヤが熱を持ちすぎる心配もある。

セパンの雨は、過去にもレースを変えてきた。2009年のマレーシアGPは、激しい雨で33周目に中断され、31周目終了時点の順位で結果が決まった（予定は56周）。ポイントは半分になった。予選の日に更新された英PlanetF1の予報では、今日の決勝のスタート時の雨の確率はおよそ50%で、レースが進むにつれて下がる見込みだ。
