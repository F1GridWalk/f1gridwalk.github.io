WORLD MEDIA LENS · 臨時号

ホンダ新体制へ。海外の見出しと、浅木泰昭の見立て。日本語では語られない3つの話と「遅いのは本当にエンジン？」の謎

ホンダのF1パワーユニット開発は、明日10月1日から新しい責任者のもとで動き出す。8月に「スペック2」を入れたあとも、海外の見出しは「F2より遅い」「70馬力遅れ」「ホンダ救済」と続いた。日本のファンには、つらい9月だったと思う。一方、元ホンダF1のPU責任者・浅木泰昭さんは、今日のweb Sportivaの連載で、負けている本質はパワーだと言い切った。海外の見出しと、日本の技術者の見立て。原文まで読んで、並べてみました。

2026年9月30日(水) 20:36 公開

1

日本では見当たらなかった話

海外の記事にだけ書かれていた話と、見出しの数字の中身です。

motor.esスペイン · スペイン語
技術

「F2より遅い」の比べ方。同じ場所では、フェラーリのハミルトンもF2より下だった

バクーの金曜、「アストンマーティンはF2の全車より遅い」という比較が世界中に広まり、日本でも報じられた。比べたのは、ゴールライン上の速度だ。スペインのmotor.esは、FIAの計測データを使ってこれに反論した。2026年のF1は、長いストレートの終わりで電気の出力が途切れる（クリッピング）ため、ゴールライン付近では減速している。電気を使わないF2は、最後まで加速を続ける。実際、同じゴールラインでは、フェラーリのハミルトン（314.1km/h）も、フェラーリのPUを積むハースのベアマン（307.3km/h）も、F2のボヤ（316.4km/h）より遅かった。一方、ストレートの途中のスピードトラップでは、フリー走行2回目のアストン（ストロール309.3km/h、アロンソ307.6km/h）が、ボヤ（298km/h）を上回っている。ただしF1の先頭（ハジャーの339.6km/h）とは約30km/hの差がある。同媒体の結びはこうだ。「この日本のメーカーが今季、笑いものすれすれなのは間違いない。でも、その理由のひとつは、F2との最高速の比較ではない」。

AutoRacerイタリア · イタリア語
噂

「ホンダは70馬力差」。その数字、同じ媒体の中で何度も変わっていた

9月1日、イタリアのAutoRacerは「ホンダのPUは、メルセデスからまだ約70馬力遅れている」「1周あたり約1.2秒に相当する」と報じ、各国で引用された。日本でも紹介されている。ところが、同じ媒体の記事をさかのぼると、数字は動いている。7月28日は、トップとの差を「90馬力と言われている」とし、新しいスペックには「35馬力、1周0.5秒ほど」の向上が見込まれると書いた。8月20日は、救済の仕組み（ADUO）で得たのは「約15馬力」で、期待の30馬力には届かなかったとした。9月1日は、オランダGPでの向上を「約17馬力」としている。ほかの媒体の見積もりも、そろっていない。英The Raceはスペック2の効果を「推定10〜30馬力」と幅をもたせ、スペインのDiariomotorは1周「0.05〜0.1秒ほど」と書いた。ホンダは具体的な数字を出しておらず、FIAも馬力の数字は公表していない。どの数字も、外から確かめる方法がないのが実情だ。

RacingNews365オランダ · 英語
報道

「ホンダ救済」は誰が求めたのか。アストンは「実態より大きく報じられた」「規則の枠組みを信頼している」

9月、FIAのベン・スレイエム会長は「アロンソを去らせるわけにはいかない」と話し、「オーナーのローレンス（・ストロール）と会った。変更を行うつもりだ」と続けた。会ったのはアストンマーティンのオーナーで、エンジンを作るホンダではない。ホンダの折原伸太郎GMの答えは「彼が何を考えているのかは分かりません」「魔法をかけてくれることはできません」だった。ここまでは日本でも報じられている。その先がある。バクーで、アストンのマイク・クラックは「大げさに伝わったのでは」と問われ、こう答えた。「あなたの言うとおりだと思う。実際に起きていたことより、大きな話にされたのかもしれない」「規則の枠組みがあって、選手権に参加するときには、それが参加の条件になる」「私たちはこの枠組みと規則を信頼している。付け加えることはあまりない」。つまり、ホンダもアストンも、公の場では追加の救済を求めていない。それでも「救済」の話は、二者の外で進んだ。

原文を読む（RacingNews365）↗同じ話を伝えた媒体：GPFans、RacingNews365

謎：それでも遅いのは、本当にエンジンだけのせい？

海外では「救済」の話まで出た。日本では、元ホンダの技術者が「本質はパワー」と言い切る。9月の証拠を、エンジン側と車体側に分けて並べました。あなたの判定を。

WHO'S RIGHT?

アストンが遅いのは、
本当にエンジンだけのせい？

新しいエンジンが入っても、アストンマーティンは15戦で3点、コンストラクターズは11チーム中10位のまま。9月のモンツァとバクーに残った証拠を、エンジン側と車体側に分けて並べる。

9月

モンツァ：直線での遅れは本物

ホンダ自身が「私たちのパワーユニットは性能が足りていない」と認めた。The Raceの分析では、アロンソはレッドブルのPUを積むマシンに対し、1コーナーまでの直線だけで0.4秒失っていた。motorsport.com日本版によると、最高速はノリスの338.1km/hに対して、アロンソは314.7km/hだった。ここは、言い逃れができない。

Honda RacingThe Racemotorsport.com 日本版
9月30日

日本・浅木泰昭「本質は、パワーがないこと」

元ホンダF1のPU責任者で、2021年にホンダをタイトルに導いた浅木泰昭さんは、今日のweb Sportivaの連載「アサキの視点」で、こう言い切った。「今、ホンダのPUがライバルに負けている本質は『パワーがないこと』です。それ以上でもそれ以下でもありません」。スペック2については、パワーは多少上がったものの小改良にとどまった、という評価だ。原因としては、今年の規則で圧縮比の上限が下がり、速く燃やすことが難しくなった点を挙げ、燃焼の速さでは新規参入のアウディにも及ばないという見立てを示している。詳しくは元の連載で読める。ホンダのエンジンを長く率いた技術者は、はっきりエンジンを指している。

web Sportiva
9月

モンツァ：ストロール「足りなかったのはパワーだ」

予選で最後列に沈んだあと、ストロールはこう話した。「シャシーはそれほど悪くなかった。取り組むべき点はいくつかあるけど、足りなかったのはパワーだ」。前のキャデラック勢との差も、コンマ8秒あった。

Formula1-Data
9月

モンツァ：でもタイム差は、3つのセクターにほぼ均等

autosport webの分析によると、予選で最速マシンとの差は、セクター1が1.166秒、セクター2が1.179秒、セクター3が1.153秒。直線の多い区間だけでなく、コーナーでも同じように遅かったことになる。エンジンだけの差なら、こうはならない。

autosport web
9月

イタリアの分析：車体は夏に1.6秒速くなった。残る差の半分近くは直線

イタリアのAutoRacerは9月22日、B仕様の車体（AMR26B）で、夏の初めから終わりにかけて他チームとの差が「全体で1.6秒縮まった」と書いた。それでもハースの1秒以上後ろ、ウイリアムズの約0.3秒後ろ。中団上位との差の「ほぼ半分は直線で積み上がっている」とし、ウイリアムズが前に出たのは「エネルギーの大きいサーキットで優位に立てるパワーユニットを生かしたから」だという。車体で縮めた。でも、直線で残っている。両方が本当だ。

AutoRacer
9月

バクー：クラック「ようやく重量制限に近いところまで来た」

軽量化の2段階目が入ったバクーで、アストンのマイク・クラックは「また少し軽量化することができた。ようやく重量制限に近いところまで来たと思う」と話した。春から指摘されてきた車体の「重さ」は、ここでほぼ解消したことになる。それでも、バクーは最後列だった。

Formula1-Data
9月

バクー：アロンソ「感触は良かった」。でも直線で毎周、抜き返された

Formula1-Dataによると、決勝でアロンソはターン3やターン7でボッタスを抜いても、メインストレートに戻るたびに順位を奪われた。本人は「感触は良かった。ソフトタイヤもうまく機能していたし、デグラデーションもかなり少なかった」と車体側を評価し、直線については「エンジンに何らかの問題があったんじゃないかと考えている」。ホンダは「データ上では何も問題を見つけていません」と答え、出力だけでなくエネルギーマネジメントやGPSも確認するとした。

Formula1-DataF1-Gate.com
9月

バクー：ストロール「シャシー側もかなり遅れを取っている」

予選21番手のあと、ストロールは「パワーが足りないし、コーナーではかなりロックアップしている」。シャシー側に前向きな材料はあるかと問われると、「ないと思う。シャシー側もかなり遅れを取っていると思う」と答えた。ドライバー自身が、両方だと言っている。

Formula1-DataHonda Racing
9月

「救済」の中身：ホンダだけの話ではない。フェラーリはもう2回使った

「ホンダ救済」と呼ばれる仕組み（ADUO）は、ホンダだけのものではない。FIAの8月の判定では、フェラーリとアウディもホンダと同じ「4％超」の区分で、3社とも今季2回・来季2回の追加アップグレードを認められた。浅木さんも同じ連載で、ホンダはオランダGPの1回にとどめると言われる一方、「フェラーリはADUOを利用した2回のアップデートをすでに投入し」ていると指摘している。また、ホンダが得た追加の予算枠1900万ドルのうち、F1-Gateによると800万ドルは実質的な「借り入れ」で、規則上は使用後の3シーズンで同じ額だけ予算枠を減らして返す。「救済」の一部は、将来の開発費を先に使うことでもある。

web SportivaF1-Gate.comF1-Gate.comFormula1-DataFIA
10月1日

事実：明日から、開発責任者が交代

ホンダの発表によると、明日10月1日付で、F1パワーユニット開発の責任者（LPL）は角田哲史さんから深尾洋一郎さんに代わる。深尾さんは制御プログラムの専門家で、HRC Sakuraのミッションルームの責任者も務めてきた。浅木さんは連載の後編で、自身がLPLだった時代から深尾さんのソフトウェアの力を高く買っていたと振り返り、新しいリーダーには「腹をくくってほしい」と期待を寄せている。責任者が代わるのは事実だ。では、アストンの遅さは、本当にエンジンだけのせいなのか。あなたはどっちだと思いますか？

証拠が示すこと分析

  1. 直線での遅れは本物。モンツァではホンダ自身が「性能が足りていない」と認め、アロンソは直線だけで0.4秒、最高速で約24km/h失っていた。浅木泰昭さんも、負けている本質はパワーだと言い切っている。
  2. 一方で、モンツァ予選の差は3つのセクターにほぼ均等で、コーナーでも同じように遅かった。バクーではストロール自身が「シャシー側もかなり遅れを取っている」と認めている。
  3. イタリアの分析では、車体は夏に1.6秒縮めたが、残る差の半分近くは直線だという。車体は良くなり、エンジンの差が目立ってきた、とも読める。
  4. 「F2より遅い」は比べ方の問題で、「70馬力差」は外から確かめられない。「救済」はホンダもアストンも公の場では求めておらず、仕組みはフェラーリやアウディにも同じように適用されている。見出しは、中身より強い。
  5. 証拠を並べると、エンジンの遅れがいちばん大きく、車体にも課題が残る。日本の技術者の見立て（A寄り）と、ドライバーや海外の分析（B寄り）。どちらを重く見るかは、あなた次第だ。

9月30日時点の証拠による判定です。セクター差は予選1周のデータで、コースの特徴にも左右されます。エンジンと車体の遅れを正確に切り分けたデータは、公開されていません。浅木さんの発言はweb Sportivaの連載「アサキの視点」第17回によります。投票はこのサイトで数えて、次のWORLD MEDIA LENSで結果を紹介します。
