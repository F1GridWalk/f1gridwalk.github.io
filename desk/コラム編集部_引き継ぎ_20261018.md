## 3. 手作りコラムの流れ
1. 案を3〜5個 → オーナーが選ぶ。
2. 書く → 別の担当が確認（直した版 .v.json）。
3. タイトル案3〜5、見出し画像案3〜4を、430px幅のPDF（最後に案のページ）で見せる → ボタンで選んでもらう。
4. OKで公開：git pull → lens/<slug>.json（published は実際の時刻 +09:00）→ python3 build.py → 画像を 1203×630 に縮めて (1,0,1201,630) で切り lens/<slug>/og.png → build → rm -rf __pycache__ → commit → pull --rebase → push → Actions を確認
   `curl -s "https://api.github.com/repos/F1GridWalk/f1gridwalk.github.io/actions/runs?per_page=1"`
5. 公開後に渡すもの：貼り付けページの Artifact（capabilities {downloads:true}、画像はダウンロードボタン付き）、note掲載イメージのPDF、画像、X投稿①②③。reserve の daily/<日付>/ に保存して push。
- 見出し画像には必ず「F1」。WORLD GRID は帯のひな形、OFF GRID は「こぼれ話」帯、DEEP は紙/黒の柱＋#号数。ひな形は reserve の desk/templates/。
- note のタグ：OFF GRID は #F1こぼれ話 #OFFGRID（自動の #WORLDGRID は外す）。タグに「・」を使わない。
- note素材：`NODE_PATH=$(npm root -g) python3 tools/col_assets.py lens/<slug>.json <out>`（画像の書き出しで出る失敗は無害）。DEEP は tools/col_assets_deep.py に入力 JSON（dek、①〜⑤、問い、続き、URL）を作って渡す。
- 貼り付けページ：desk/templates/paste_page_*_example.html の head/tail を流用し、本文は コピー用.html の <div id="body"> の中身。本文の末尾に </div> が1つ余るので取る。
- ローカルのプレビュー：lens/ に JSON をコピー → build → `python3 -m http.server 8765` → PDF → 元に戻す。サーバーは**別のコマンドで** `pkill -f "m http.serve[r] 8765"`（同じ行で止めるとシェルごと落ちる）。
