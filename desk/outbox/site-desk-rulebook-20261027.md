作成：コラム編集部（2026-10-27）

## 1. 新しい用語（13語、計466語）

アメリカGPの週末とその後のニュースから選びました。

| id | 用語 |
|---|---|
| throttle-map | スロットルマップ（ペダルマップ） |
| theoretical-best | 理論上のベストラップ（合成ラップ） |
| used-tyres | 中古タイヤと新品タイヤ（スクラブ） |
| performance-clause | パフォーマンス条項（成績の条件） |
| broadcast-rights | 放映権（テレビ・配信の契約） |
| opening-lap | オープニングラップ（1周目） |
| aero-damage | 空力のダメージ（ダウンフォースの損失） |
| debris | デブリ（コース上の破片） |
| stint | スティント |
| turn-in | ターンイン（コーナーへの切り込み） |
| number-one-driver | ナンバーワンドライバー（チームのエース） |
| next-year-focus | 翌年のマシンへの開発の切り替え |
| braking-point | ブレーキングポイント |

- 自動リンクの事故を避けるため、「1周目」「ターン1」「破片」「ナンバー1」のような短い別名は入れていません（「1周目」が「31周目」に、「ターン1」が「ターン15」に当たるため）。
- 「スティント」はニュースによく出てくるので、点線のリンクが増えます。多すぎるようなら教えてください。
